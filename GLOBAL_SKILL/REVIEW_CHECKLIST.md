# Review Checklist

## Scope Check

- 是否只修改任务允许范围。
- Changed Files 是否与 Commit Diff 一致。
- 是否存在未授权的产品、系统、Session 或 Registry 变更。

## Evidence Check

- 是否有来源证明关键结论和完成声明。
- Evidence Summary 是否可追踪到文件、来源或提交。
- 是否明确披露证据缺失与限制。

## Data Integrity

- 是否混入未经确认数据。
- 已确认、未验证和冲突信息是否明确分离。
- 是否存在 AI 推测被标记为事实。

## Output Check

- 输出文件是否完整并存在于审核 Commit。
- 输出结构是否符合 Output Standard 和任务要求。
- Completion Criteria 是否逐项满足。

## State Check

- Project State、Task Queue、Agent Registry 和 Session 状态是否一致。
- 状态流转是否经过 Supervisor Review。
- 是否满足进入下一阶段条件。
