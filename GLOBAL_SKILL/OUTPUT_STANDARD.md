# Output Standard

所有 Work 输出必须包含以下部分：

1. Summary
2. Execution Method
3. Sources
4. Result
5. Created Files
6. Issues
7. Next Action

若某部分没有内容，必须明确填写 `None`，不得省略。

## Work Completion Required Fields

所有 Work 完成输出还必须包含以下强制字段：

Evidence Summary:

说明使用了哪些证据、证据位置、适用范围和验证状态。没有证据时必须填写 `None` 并说明原因。

Risk Items:

说明未解决风险、冲突、缺失信息和下游限制。没有已知风险时必须明确填写 `None`。

Changed Files:

完整列出 Commit 中所有新增、修改、删除或移动的文件，不得只列主要文件。

Commit Hash:

提供可由 Supervisor 在 GitHub 验证的完整 Git commit hash。
